# Simple Answer: What Button to Press?

## 🎯 Quick Answer

**Press BUTTON A** (the left button on the front of Micro:bit) after you see the code start running.

---

## 📝 Detailed Steps

### Step 1: Flash the Code
- Copy code from web app
- Flash to Micro:bit via https://python.microbit.org/
- Wait for download to finish

### Step 2: Power On Micro:bit
- Unplug from USB
- Use battery pack or USB power bank
- Micro:bit will turn on automatically (no power button!)

### Step 3: Watch the Display
You should see:
1. **✓ (checkmark)** - Code is loaded ✅
2. **"READY"** scrolling text
3. **"A"** letter - This means "Press button A"

### Step 4: Press Button A
- **Button A** is the **LEFT button** on the front
- Press it once
- You'll see **😊 (happy face)** - means it's ready!

### Step 5: Connect in Web App
- Go to web app
- Click "Connect" button
- Select your Micro:bit
- Done! ✅

---

## ⚡ Alternative: No Button Press Needed

**If you don't want to press a button:**
- Just **wait 5 seconds** after the checkmark appears
- The code will auto-start
- Then connect in web app

---

## 🔄 If It's Not Pairing

### Try This:
1. **Press RESET button** (small button on the back)
2. **Wait for checkmark** to appear
3. **Press Button A** (or wait 5 seconds)
4. **Try connecting** again

### Still Not Working?
1. **Re-flash the code** (maybe it didn't upload correctly)
2. **Check Bluetooth is ON** on your computer
3. **Use Chrome or Edge** browser (required!)
4. **Make sure Micro:bit is powered** (not just plugged in)

---

## 🎯 Visual Guide

```
What You'll See:
1. ✓ (checkmark)        ← Code loaded
2. "READY" scrolling     ← Initializing
3. "A" letter            ← Press button A now!
4. 😊 (happy face)       ← Ready for pairing!

Then connect in web app!
```

---

## ✅ Summary

- **No power button** - Micro:bit turns on automatically
- **RESET button** (back) - Restarts the Micro:bit
- **Button A** (front left) - Starts pairing mode
- **Button B** (front right) - Not needed

**Just press Button A after you see the checkmark, then connect!**
